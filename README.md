📊 Codveda Data Analytics Internship: Telecom Churn Project
Project Overview
This repository contains the end-to-end data analytics workflow completed during my internship at Codveda Technologies. The project is structured into three progressive levels, moving from raw data preparation to advanced predictive modeling and executive-level business intelligence.

Goal: Analyze customer behavior to predict churn and provide actionable insights to safeguard a ₹24K monthly revenue stream.

📂 Internship Milestone Breakdown
📍 Level 1: Data Foundations & EDA
Task 1: Data Cleaning & Preprocessing: Handled missing values, corrected data types, and prepared a dataset of 3,000+ records using Python (Pandas).

Task 2: Exploratory Data Analysis (EDA): Identified key correlations, such as the relationship between service calls and churn probability.

Task 3: Basic Data Visualization: Created initial distributions and count plots to understand the subscriber base.

Key Insight: Discovered that churn spikes significantly after the 3rd customer service call.

📍 Level 2: Statistical Modeling & Advanced Analytics
Task 1: Regression Analysis: Modeled the relationship between account length, charges, and customer behavior.

Task 2: Time Series Analysis: Analyzed call patterns and usage trends to identify peak churn periods.

Task 3: Clustering Analysis (K-Means): Segmented customers into distinct groups based on usage behavior, identifying the "High-Risk International" cluster.

📍 Level 3: Predictive Power & Business Intelligence
Task 1: Predictive Modeling (Classification): Developed a Random Forest Classification model to predict which individual customers are likely to leave.

Task 2: Executive Dashboard (Power BI): Built a high-performance interactive dashboard featuring:

AI Decomposition Tree: Root cause analysis for churn drivers.

Geographic Shape Map: Spatial heatmapping of revenue risk across the US.

Priority Risk Table: Segmenting the Top 5 states by financial impact.

Interactive Slicers: Dynamic filtering by State and International Plan status.

🛠️ Technical Stack
Languages: Python (Pandas, Scikit-Learn, Matplotlib, Seaborn)

Tools: Power BI Desktop, Jupyter Notebooks

Techniques: K-Means Clustering, Random Forest Classification, Regression, Time-Series Analysis

📈 Final Results & Business Recommendations
Retention Alert: Implement an automated retention offer for any customer reaching their 3rd service call.

Product Optimization: The International Plan has a 30% churn rate; recommend a pricing/service audit for this specific segment.

Revenue Recovery: By targeting the high-risk states identified in the Priority Risk Table, the company can potentially recover up to ₹12,000 in at-risk monthly revenue.
